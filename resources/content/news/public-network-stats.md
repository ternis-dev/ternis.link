title: Network stats are now public
date: 2026-09-26
description: Aggregate counts for the whole ternis.link network — totals, per-day charts, per-domain and top-link tables. No login, no personal data.
---

Curious how the network is doing? The [network stats](/pages/stats) page answers with aggregate-only analytics: all-time totals, links created and clicks per day for the last 30 days, a [per-domain breakdown](/pages/stats/domains), and the [most-clicked public links](/pages/stats/links).

Privacy is structural, not promised: every number is a count grouped by day or domain. No IPs, no user agents, no referrers, no per-user rows ever leave the database for these pages — there is simply nothing personal to leak. Removed links stay counted (nothing is ever deleted), so all-time totals stay complete.

Every stats page also ships a Markdown twin (look for the `.md` URLs) for crawlers and agents.
